**R-1 — 5f9db88 (still at the tip). [medium] Rule: a plausible mutation must
be caught; no test green because of a choice it made about its own fixture
(CONTRIBUTING). Seen: "an id with any byte not zero is hex" is held at one byte

    left-aligned (`missing_trace_id`);
  - a little-endian counter id such as `0100000000000000`;
  - ids ending in two or four zero bytes.

- A second probe with the first byte 1 and the rest zero turns all six red.

**R-2 — 5f9db88 (still at the tip). [medium] Rule: the protobuf path yields
what the JSON path yields for the Collector's JSON (D29: "a protobuf-only
behaviour with no JSON counterpart is a halt, not a choice"); losslessness
