## Findings

### 1. BLOCKER — shuffled-input determinism is violated for records with no `span_id`

`spanweave/adapters/openinference.py:199` and `otel_genai.py:290`:

    source_key = span_id if span_id is not None else str(index)

Reproduced directly at HEAD — two span-id-less records, input order reversed:

    forward : [('sw_cde39f998fc177dc', 'beta'), ('sw_f3adffe8eba5ff98', 'alpha')]
    reversed: [('sw_cde39f998fc177dc', 'alpha'), ('sw_f3adffe8eba5ff98', 'beta')]

The id *set* is stable; the id-to-record *binding* is not. `sw_cde39f998fc177dc`
names a different span depending on line order. This is a direct violation of
CLAUDE.md invariant 4 and of AGENT.md's non-optional "shuffled-input
determinism" check.

Why nothing catches it: the shuffle tests
(`tests/test_determinism.py:205-219`) run only over `WORKED_RECORDS`, and **0 of
117** corpus records lack a span id. The gate is correctly shaped and blind to
this input class.

Attribution: **pre-existing**, dating to Phase 0/1, present identically at
`b44c3a5^` and `b44c3a5`. A3 neither introduced nor worsened it — but A3
*removed the obstacle* to fixing it, because after reader dedup two surviving
span-id-less records always differ, so a digest-derived `source_key` is now
total. The malformed-record path (`openinference.py:176`, `otel_genai.py:267`)
uses the same positional key.

E1 flagged this; it has no batch. **E3 will collide with it.** It wants its own
batch before E3, and the fix is A3's own reasoning applied one layer out.

### 6. CONCERN — B1's field test cannot catch the failure mode its design invites

`test_an_annotated_graph_carries_every_field_a_built_one_has` asserts every
non-`annotations` field equals the **parent's**. `_with_annotations` bypasses
`__post_init__`, so a future `Graph` field *derived from* `annotations` would
carry a stale value and this test would assert stale == parent's and pass. It
proves "no field goes missing"; the risk is "a field goes stale". Fix for a
later batch: compare against a fully rebuilt graph, not the parent.

The sharing itself is **sound** — every write to `_index`/`_out`/`_in` is an
`object.__setattr__` in `__post_init__` over freshly built locals; the fields are
typed `Mapping`, so `mypy --strict` rejects in-place writes; and the
"nodes unchanged" precondition is enforced by construction, since
`_with_annotations` takes only an `AnnotationStore`. Probing confirmed
all-or-nothing behaviour across an exception raised inside the caller's iterable.

### 7. CONCERN — A3's content dedup can collapse two real spans, and SPEC argues one side
